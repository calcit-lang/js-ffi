# Executable Calcit recipes

Generated by `yarn api:generate` from `examples/recipes.json` and the Cirru source files.

Each source is a quoted Calcit definition accepted by `calcit edit def --file`. The checker injects its imports and schema into a temporary snapshot, then compiles the actual recipe used by runtime tests.

Run `yarn check:api`, `yarn test:node`, and `yarn test:browser`. Browser tests require Chromium (`yarn playwright install chromium`). Node file tests use a temporary directory and remove it in finally. The file recipe itself overwrites `example.txt` in the caller-provided directory.

## Encode a search query without manual URL escaping

Runtime: browser, node.

Imports:

```text
js-ffi.shared :as shared
```

Schema:

```text
:: 'Fn $ {} (:args $ [] 'String) (:return 'String)
```

Source: [examples/query-string.cirru](../examples/query-string.cirru)

```text
quote $ defn query-string (term)
  let
      params $ shared/search-params-create |page=1
    shared/search-params-set! params |q term
    shared/search-params-string params
```

Runtime verification: [tests/recipes.mjs](../tests/recipes.mjs).


Schema:


Source: [examples/text-file.cirru](../examples/text-file.cirru)

```text
quote $ defn text-file (directory text)
  let
      target $ node/path-join directory |example.txt
    node/write-text! target text

```
