# 0.2.1-alpha.1 发布准备

前置：[已合并的 #122](https://github.com/calcit-lang/js-ffi/pull/122)。该版本更新提交本身不创建 tag，也不表示已经发布。CLI 与 runtime 保持 Calcit 0.22.0，包继续通过 Git/Calcit 模块分发，不发布到 npm。

## 内容与兼容边界

- 增加 Calcit `CanvasContextHost` 原生路径/描边方法及样式字段，无新增生产 JS wrapper。
- 保留已有矩形 API 与历史版本 tag；手写假宿主使用新方法时须补齐能力。
- 字符串与数值值域采用原生 Canvas 规则；当前 path 不随 save/restore 恢复。详见[接口契约](../canvas-rect-batches.md)。
- Quamolit 下一切片消费这些接口恢复摆动树圆头/圆连接；此版本不提供 Scene IR、树形逻辑或 GPU 绘制。

## 发布门禁

1. 合并版本更新 PR，确认该提交的 Actions 全绿。
2. 核对 `deps.cirru` 和 `package.json` 版本均为 `0.2.1-alpha.1`，Calcit CLI/runtime 均为 0.22.0；执行 `yarn install --immutable && yarn test && yarn build:browser`。
3. 经发布授权后，在已验证的合并提交创建同名 tag 和 GitHub prerelease；不移动或覆盖历史 tag，也不把 alpha 标为稳定 latest。
4. Quamolit 将 Calcit 依赖与现存 Yarn 引用一并更新到该 tag，重新安装并更新 lockfile；通过真实调用、固定时间画面及完整 demo 导航验证，再提交下游 PR。

浏览器覆盖 18 组 cap/join/开放闭合像素对照；全量类型负例 24 项。实际运行结果以本 PR/CI 为准；没有真实 WebGPU adapter 时，只报告 Canvas 和回退结果，不算 GPU 验收。

本说明不是自动发布脚本，不需要新增运行时依赖或调整既有 linker。
