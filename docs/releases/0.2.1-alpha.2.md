# 0.2.1-alpha.2 发布准备

前置：已合并的 [#125](https://github.com/calcit-lang/js-ffi/pull/125)。本文件和版本号更新
本身不创建 tag，也不代表已发布。Calcit CLI/runtime 仍为 0.22.0；模块通过 Git/Calcit
分发，`@calcit/js-ffi` 不发布到 npm。

## 新能力及边界

- `CanvasContextHost` 增加 `fillText`、`measureText`、字体和文字对齐的 Calcit 类型化原生映射。
- 只读 `CanvasTextMetricsHost.width: Number` 返回 CSS 像素宽度；不保证字体已加载，也不验证
  原生 String 属性的值域。
- 独立 Calcit recipe 经普通模块引用、搬移后的 JS 输出和真实 Chromium 像素对照验证；
  不新增生产 JS wrapper、Scene IR 或批量绘制协议。
- 保持现有 Canvas 矩形与路径接口、历史 tag 不变。Quamolit 需在新 tag 发布后移除局部
  `raw-fill-text!` 适配，并保留同源画面对照。

## 发布门禁

1. 合并版本更新 PR，确认其精确 main SHA 的 Check workflow 成功。
2. 确认 `deps.cirru` 与 `package.json` 均为 `0.2.1-alpha.2`，Calcit 依赖仍为 0.22.0；
   执行 `yarn install --immutable && yarn api:generate && yarn test && yarn build:browser`。
3. 在已验证的 main 提交创建同名 annotated tag 与 GitHub prerelease；不移动已有 tag，
   不把 alpha 标为稳定 latest，也不发布 npm。
4. Quamolit 同步 Calcit 模块依赖与 Yarn 引用，重新安装、构建，运行严格类型及固定画面浏览器
   像素测试；下游 PR 合并后再关闭 js-ffi #124。

本机无 WebGPU adapter 时只报告 Canvas 验收，不视作 GPU 验证。
