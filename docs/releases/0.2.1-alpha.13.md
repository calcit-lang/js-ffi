# js-ffi 0.2.1-alpha.13

本预发布版本准备对齐已发布的 Calcit CLI / npm `@calcit/procs` **0.29.0-alpha.2**。js-ffi 仍通过 Git tag 分发，不发布 npm 包；模块版本与 Calcit 工具链版本分别记录在 `deps.cirru` 和 `package.json` 中。

## 变化

- 同时更新 CLI pin、npm runtime、lockfile 和 Yarn 的精确版本准入项，保留单一 runtime 实例。
- 模块 API、Promise executor/payload 合同、事件继承声明、URLSearchParams 受检转换及运行时语义保持不变。
- 两个 DOM 状态 decoder 与 `normalize-error` 的三个字面量分派从已弃用的 `case-default` 改为 `match` 加末尾 `_` 分支，保持已知变体、未知字符串和原有错误字段读取次数；不放宽质量 baseline。
- 匹配的新工具链包含空 Enum/递归输入推导、EDN 数字根格式化、拒绝 EDN 不隐式打印原始值，以及继承方法查询修复。Agent 可继续使用 `calcit query type`、`query def` 和模块 `docs` 入口发现合同。

## 升级

只有 js-ffi `0.2.1-alpha.13` 同名 Git tag/prerelease 发布后才更新应用依赖；main 或打开的 PR 不是发布版。

1. 保留原版本和测试基线。需要旧 CLI 的历史改写先按 Calcit 升级指南完成。
2. 安装 Calcit CLI `0.29.0-alpha.2`，核对 `calcit -v`。
3. 同时将应用的 Calcit pin 与 npm `@calcit/procs` 更新为 `0.29.0-alpha.2`，js-ffi pin 更新为 `0.2.1-alpha.13`。
4. 通过 Caps 和包管理器安装固定版本，执行 `caps verify --toolchain`，确认没有工具链 mismatch 或重复 runtime。
5. 保留应用原断言，执行严格检查、定义附带测试、生成 JS 与实际 Node/浏览器回归；Promise 观察值仍通过 decoder 验证后进入具体类型。

安装后，在应用项目目录查询：

```sh
calcit docs list --module js-ffi
calcit docs read typed-host-boundary.md --module js-ffi
calcit query type js-ffi.browser/KeyboardEventHost
```

## 限制

- 本版本不提供新的宿主能力，也不改变 Promise 的 native/WASM unsupported 边界。
- Calcit 0.29.0-alpha.2 不包含新的裸 `requires` 语法；继续使用已发布的 `'requires Parent` 声明。
- 模块测试不能替代完整 Respo、Diary 或其他业务应用的升级验收。
- 已有 alpha.12 tag 和它匹配的 Calcit 0.29.0-alpha.1 不改写。
