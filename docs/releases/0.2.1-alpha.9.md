# js-ffi 0.2.1-alpha.9

本预发布版本补齐浏览器 Canvas2D 的类型化图像绘制入口，供 Quamolit Folding Fan 移除项目内的九参数 `drawImage` 适配。

## 新增接口

`js-ffi.canvas-batches` 新增 `draw-image-at!`、`draw-image-sized!`、`draw-image-crop!`，分别对应 `CanvasRenderingContext2D.drawImage` 的三、五、九参数形式。接收者是 `CanvasContextHost`，图像是 `js-ffi.browser/ImageHost`，坐标和尺寸均为 `Number`；这些函数只适用于浏览器目标且要求 `:js-ffi` feature。

它们通过类型化 external-object trait 直接调用原生方法，不增加 JS snippet、`Dynamic` 公共参数或 `unsafe-coerce`。调用方仍需自行检查 `image-decode!` 的 `Result`。零宽矩形、未就绪图像和错误宿主值遵循浏览器自身行为；接口不伪造成功、默认像素或异常转换。

## 验证与迁移

关联 [PR #142](https://github.com/calcit-lang/js-ffi/pull/142) 和 [issue #141](https://github.com/calcit-lang/js-ffi/issues/141)。Calcit 0.24.3 / Node 24 的 `yarn test` 全绿：315 个公共 API 记录、45 个非法类型消费者被拒绝、21 项 Node 测试及 509 条真实 Chromium 断言通过。Chromium 测试逐像素检查原尺寸、缩放和裁剪，并验证无效输入的宿主行为。本机没有 WebGPU 硬件 adapter，因此不宣称该部分已验收。

仅在本版本的 `deps.cirru`、`package.json` 与 GitHub annotated tag / prerelease 全部一致，且精确 main SHA 的 Check workflow 成功后，下游才应升级。Quamolit 可将原 `draw-image-crop!` 适配替换为本模块 API；动画采样、Scene、切片调度仍归 Quamolit 所有。
