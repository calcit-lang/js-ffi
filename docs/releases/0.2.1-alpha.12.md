# js-ffi 0.2.1-alpha.12

本预发布版本对齐实际已发布的 Calcit CLI / npm `@calcit/procs` **0.29.0-alpha.1**，与模块自身版本 `0.2.1-alpha.12` 区分。本模块仍通过 Git tag 分发，不发布 npm 包；npm 中的 `@calcit/procs` 是 Calcit runtime，不是这个模块。

## 变化与边界

- `KeyboardEventHost` 与 `MouseEventHost` 现在用 `('requires EventHost)` 声明继承：键盘和鼠标事件可以直接传给要求 `EventHost` 的位置（例如 `event-stop-propagation!`），并能读取 `:event-type`、调用 `.prevent-default!` 等共享成员，它们不再各自重复声明 `.prevent-default!`。反方向（`EventHost` 到 `KeyboardEventHost`）仍然需要适配器里的宿主种类检查，`PointerEventHost` 与 DOM 元素 trait 保持独立。
- `js-ffi.shared/normalize-error` 对 `name` 与 `message` 增加已有的 `expect-string` 校验，使 `JsError` 字段在 Calcit 0.29.0-alpha.1 的 lowering 后仍被证明为 String；两条分支原本就返回字符串，运行时行为不变。
- `deps.cirru`、npm runtime、lockfile 与 Yarn quarantine 例外使用相同的精确版本 `0.29.0-alpha.1`。本版本还包含 main 上已合并、尚未发布的 [#159](https://github.com/calcit-lang/js-ffi/pull/159)（新增 23 个增量宿主 API，见 `docs/standard-host-adapters.md`）；除此之外，已有 API、异步、取消、文件和浏览器资源语义不夹带改变，已审阅的宿主断言 baseline 不增加。
- 新增 type-contract 测试：键盘/鼠标事件传入 `EventHost` 参数通过检查，`EventHost` 传入键盘事件参数被拒绝，且不含继承声明的源码上前一个用例会失败。

## 升级顺序

只有 `0.2.1-alpha.12` annotated tag 与 GitHub prerelease 发布后才更新应用的模块依赖，不能把尚未发布的 main 当成发布版。

1. 安装 Calcit CLI `0.29.0-alpha.1`，核对 `calcit -v`。
2. 将应用 `deps.cirru` 的 Calcit 版本与 npm `@calcit/procs` 精确版本同时调整为 `0.29.0-alpha.1`，再更新 js-ffi 模块版本为 `0.2.1-alpha.12`。
3. 执行模块安装与 npm 安装，确保所有依赖使用同一个 runtime 实例。
4. 运行 `caps verify --toolchain`、应用严格检查、实际 Node/browser 构建和项目测试。

Calcit `0.29.0-alpha.1` 仍是预发布版本，不代表 Calcit 0.29.0 milestone 全部完成。
