# 0.2.1-alpha.3 发布准备

本版本衔接 [Calcit 0.24.3](https://github.com/calcit-lang/calcit/releases/tag/0.24.3)
的控制流类型推断修复。版本号更新本身不代表已经发布；只有同名 annotated Git tag
与 GitHub prerelease 创建后，才可作为下游依赖。模块仍通过 Git/Calcit 分发，
`@calcit/js-ffi` 不发布到 npm。

## 用户可见变化

- `element-style-get` 在正常分支直接返回 `Option<String>`，错误分支直接 `raise`；
  去掉为旧类型推断添加的 `&unit` 预检查和额外 `let`。空属性仍返回 `none`，
  畸形宿主对象仍报告具体的 JS FFI 契约错误。
- `document-append-body!` 通过 `DocumentHost.body` 与类型化的 `append-child!`
  操作 DOM，不再直接调用未类型化的 `js/document.body.appendChild`。成功时仍返回
  `Unit`；当 `document.body` 尚不存在时，现在报告明确的契约错误，而不是原生
  JavaScript `TypeError`。
- 没有新增生产 JavaScript wrapper、`unsafe-coerce` 或 Dynamic 公共类型。

## 验证范围与限制

关联 [PR #133](https://github.com/calcit-lang/js-ffi/pull/133) 的 Calcit 0.24.3 / Node 24
全量 `yarn test` 已通过：305 个公共 API 记录、7 个 recipe、35 个非法类型消费者拒绝、
18 项 Node 测试，以及 485 条真实 Chromium 断言。测试覆盖样式读取、缺失属性、
错误类型值、缺失的 `document.body`。静态质量预算不回退，`unsafeCoerce` 为 47。
本机没有 WebGPU 硬件 adapter，相关硬件行为和性能仍未验证；
[总 issue #112](https://github.com/calcit-lang/js-ffi/issues/112) 不因此关闭。

发布门禁：版本 PR 合并、精确 main SHA 的 Check workflow 成功，且
`deps.cirru` / `package.json` 均为 `0.2.1-alpha.3` 后，才创建同名 annotated tag
与 GitHub prerelease。下游通过精确 tag 升级；不移动历史 tag，也不把 alpha
标记为稳定 latest。
