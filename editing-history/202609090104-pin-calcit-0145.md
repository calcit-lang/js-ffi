# Pin the released Calcit 0.14.5 toolchain

Calcit 0.14.5 was published from the verified core release commit containing
the target-aware `analyze check-public` contract. The consumer now pins both
`deps.cirru` and `@calcit/procs` to 0.14.5 and removes the temporary Cargo
installation from CI.

This makes the readable released version the source of truth while retaining
the candidate revision and validation evidence in the earlier migration history.
