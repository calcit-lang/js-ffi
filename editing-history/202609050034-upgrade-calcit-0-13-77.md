# Upgrade js-ffi to Calcit 0.13.77

The repository now declares Calcit 0.13.77 in `deps.cirru` and pins the JavaScript runtime package to the matching `@calcit/procs` 0.13.77 release. Keeping these versions exact ensures that the native compiler checks and generated Node/browser runtime use the same language baseline.

The 0.13.77 GitHub release asset named `calcit` is an x86-64 Linux ELF binary and cannot execute on the arm64 macOS validation host. Local compiler checks therefore use a 0.13.77 binary built from the same release source with the stable-Rust packaging fix from calcit#660; the JavaScript checks use the published npm package.

The canonical Snapshot does not require a migration for this release. Validation covers immutable package installation, caps resolution, formatting, static quality and unsafe-boundary audits, Node and browser entry checks, runtime contracts, and the production browser build.
