# Upgrade js-ffi to Calcit 0.13.77

The repository now declares Calcit 0.13.77 in `deps.cirru` and pins the JavaScript runtime package to the matching `@calcit/procs` 0.13.77 release. Keeping these versions exact ensures that the native compiler checks and generated Node/browser runtime use the same language baseline.

The Calcit 0.13.77 tag resolves to source commit `5915ccf38ef3b57ea26897599646eefdbc9e3ba6`. Its GitHub release asset named `calcit` is an x86-64 Linux ELF binary and cannot execute on the arm64 macOS validation host. The local compiler checks therefore used an explicitly identified test artifact, not the published release binary: Calcit PR commit `98c0bbb826f74681122e32d16da7329bfe232ae9`, based on `0de0c498d51ba033e0f70a9e285b905f8109f482`, with the calcit#660 test patch applied to `src/ffi_interface_ir.rs` and `src/runner/preprocess/mod.rs`. That patch replaces unstable match-arm `if let` guards with stable control flow; the Calcit core test, Clippy, package, and install checks passed for the artifact. The JavaScript checks use the published npm package.

The canonical Snapshot does not require a migration for this release. Validation results:

- `yarn install --immutable`, `caps --strict --ci`, and `caps verify --toolchain` passed with exact version 0.13.77.
- `calcit calcit.cirru edit format` produced no Snapshot diff.
- `yarn check`, `yarn check:quality`, and `yarn audit:unsafe` passed with no increase from their baselines.
- `yarn check:node`, `yarn check:browser`, `yarn run:node`, `yarn test:contract:node`, and `yarn test:contract:browser-node` passed.
- `yarn build:browser` passed under the CI-matching Node 24.19.0 runtime.
