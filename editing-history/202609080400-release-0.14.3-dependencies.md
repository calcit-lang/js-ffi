# Validate the released query protocol

- Pin the repository and JavaScript runtime to Calcit 0.14.3, the first published release containing complete structured FFI query metadata.
- Upgrade the remaining direct development dependencies to the latest registry versions available during validation: Playwright 1.63.0 and Vite 8.2.2.
- Regenerate the Yarn lockfile and rerun the catalog, type, Node, browser, quality, and tooling suites against published packages.

Verification used the crates.io Calcit 0.14.3 CLI and npm `@calcit/procs` 0.14.3. The complete `yarn test` suite passed with 165 catalog records, 4 recipes, 7 rejected invalid consumers, 5 tooling tests, 63 Node assertions, and 149 Chromium 153 assertions; the browser page reported no uncaught exceptions or console errors. The Vite 8.2.2 production build also completed successfully.
